# Исправление проблемы с выводом звезд

## Проблема
При нажатии на кнопку "Вывод звезд" в меню выводов появляется ошибка "Ошибка при отправке заявки на вывод".

## Решение

### 1. Настройка сервера
Сервер для обработки запросов на вывод уже настроен и запущен:
- Файл: `server-withdrawal-example.js`
- Порт: 8080
- API endpoint: `http://localhost:8080/api/withdrawal/create`

### 2. Исправления в клиентском коде
Внесены следующие изменения в `main.js`:

#### 2.1. Улучшена инициализация Telegram WebApp
- Добавлена проверка доступности Telegram WebApp API
- Создана заглушка для тестирования в обычном браузере

#### 2.2. Улучшена функция получения данных пользователя
- Добавлены тестовые данные для разработки
- Функция теперь работает как в Telegram, так и в обычном браузере

#### 2.3. Добавлена отладочная информация
- Логирование данных для подписи
- Логирование сгенерированной подписи
- Подробная информация об ответе сервера

### 3. Исправления в серверном коде
В `server-withdrawal-example.js` упрощена проверка подписи для устранения проблем с `crypto.timingSafeEqual`.

### 4. Тестирование
Созданы тестовые страницы:
- `test_withdrawal.html` - для тестирования API
- `test_signature.html` - для тестирования генерации подписи

## Как протестировать

### 1. В обычном браузере
1. Откройте `index.html` в браузере
2. Откройте консоль разработчика (F12)
3. Перейдите в меню выводов
4. Выберите сумму и нажмите "Подтвердить вывод"
5. Проверьте логи в консоли

### 2. Через тестовые страницы
1. Откройте `test_withdrawal.html` для тестирования API
2. Откройте `test_signature.html` для проверки генерации подписи

## Проверка работы

### 1. Проверка сервера
```bash
curl http://localhost:8080/api/info
```

### 2. Тест API с валидной подписью
```bash
curl -X POST http://localhost:8080/api/withdrawal/create \
  -H "Content-Type: application/json" \
  -d '{"user_id": 123456789, "amount": 1000, "app_transaction_id": "tx_test_123", "signature": "2ee7e81d3706575ab1857e6a48a2f1d8fb28d4b90208994b1ee659057ddc0245"}'
```

## Возможные причины ошибок

1. **Сервер не запущен** - убедитесь, что `server-withdrawal-example.js` запущен
2. **Неправильный секретный ключ** - проверьте соответствие ключей в клиенте и сервере
3. **Проблемы с CORS** - сервер настроен для работы с локальными доменами
4. **Ошибки в консоли браузера** - проверьте консоль на наличие ошибок JavaScript
